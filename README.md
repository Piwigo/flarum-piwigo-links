# Piwigo Links

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/piwigo/flarum-piwigo-links.svg)](https://packagist.org/packages/piwigo/flarum-piwigo-links) [![Total Downloads](https://img.shields.io/packagist/dt/piwigo/flarum-piwigo-links.svg)](https://packagist.org/packages/piwigo/flarum-piwigo-links)

A [Flarum](https://flarum.org) extension. Turns topic:123, post:123, svn:123 and extension:123 into links on the piwigo.org forums

## Installation

Install with composer:

```sh
composer require piwigo/flarum-piwigo-links:"*"
```

## Updating

```sh
composer update piwigo/flarum-piwigo-links:"*"
php flarum migrate
php flarum cache:clear
```
